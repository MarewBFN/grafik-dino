# DinGO

DinGO to desktopowa aplikacja do generowania grafików pracy dla sklepów Dino.

Technologie:

- Python
- PySide6
- Google OR-Tools CP-SAT

Najważniejsze cele projektu:

- poprawny generator
- prosty interfejs
- możliwość ręcznej edycji grafiku
- stabilność

Kod ma być prosty.

Projekt rozwija jedna osoba.

Czytelność jest ważniejsza od "idealnej architektury".
